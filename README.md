# 🎯 Entry Recommendation Service

> **שירות חכם להמלצת משתתפים לאירועים מבוסס AI ו-Vector Search.**  
> פרויקט גמר המיישם עקרונות מתקדמים בהנדסת AI, ארכיטקטורת תוכנה, אבטחה ובדיקות.

---

## 📌 סקירה כללית

השירות משתלב עם מערכת ניהול הכניסות הקיימת (`tishrei-entry-backend`) ומספק המלצות מדויקות של משתתפים לאירועים חדשים.
התהליך מתבסס על:
1. **פרופיל התנהגותי דטרמיניסטי:** ניתוח היסטוריית כניסות (שעות פעילות, אחוזי נוכחות, קטגוריות מועדפות) ללא הלוצינציות.
2. **מאגר וקטורי (ChromaDB):** המרת פרופילי המשתתפים ל-Embeddings וביצוע חיפוש דמיון קוסינוס (Dense Search) מול מאפייני האירוע.
3. **דירוג ונימוק מבוסס AI (LLM Scorer):** שימוש ב-Grounded Prompts (פורמט PCTCO) לסינון ומתן ציון (0-100) עם הסבר מנומק בעברית.

## 📐 ארכיטקטורה

```text
[ Existing Backend (MongoDB) ]
            │
            ▼ (קריאת נתונים)
[ Profile Engine ] ──> חישוב שעות ונוכחות ──> [ ChromaDB (Vectors) ]
                                                        │
[ Event Details ] ──────────────────────────────────────┘
            │  (Top-K Candidates)
            ▼
     [ AI Scorer (LLM) ] ──> Grounded Generation (0-100 + הסבר בעברית)
            │
            ▼
[ Recommendation Response ]
```
